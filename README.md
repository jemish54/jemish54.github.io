# Jemish Mavani — Engineering Portfolio

Personal portfolio and technical showcase of **Jemish Mavani**, founder of **Solenyx Studio** and Full-Stack Mobile, Distributed Backend & AI Orchestration Engineer.

Live site: [jemish54.github.io](https://jemish54.github.io)

---

## Technical Highlights

- **Framework**: Next.js 15 (React 19, TypeScript, App Router)
- **Styling**: Tailwind CSS v4 with custom cyber-minimalist glassmorphism
- **Interactivity & Effects**:
  - Interactive **System Architecture Visualizer** (AstroSight RAG engine & TracXpense graph settlement)
  - Raycast-style **Command Palette** (`Cmd + K` / `Ctrl + K`)
  - Interactive dockable **Terminal / CLI Easter Egg**
  - Ambient mouse-following **Spotlight Canvas**
  - Filterable **Showcase Bento Grid** (AstroSight, TracXpense Pro, Scorecord, Lanternova)
- **Performance**: Pre-rendered static HTML export (`output: 'export'`) with instant first-contentful paint.

## Development

```bash
# Install dependencies
bun install

# Run local development server
bun dev
# or
make dev

# Build static production export
bun run build
# or
make build

# Deploy to GitHub Pages
make deploy
```
